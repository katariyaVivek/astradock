# AstraDock Roadmap

Milestones are sequential. A milestone is complete only when its lesson/model,
implementation, tests, and stated completion criteria are all satisfied. Future
items describe intent and must not be read as implemented capabilities.

Status vocabulary:

- **IMPLEMENTED**: completion criteria have been verified.
- **IN PROGRESS**: work exists but at least one completion criterion is not yet
  verified.
- **PLANNED**: no implementation claim is made.

| Milestone | Status | Objective | Concepts learned | Deliverables | Tests | Completion criteria |

| M08 Attitude propagation | PLANNED | Advance spacecraft orientation from angular rate. | Quaternion kinematics, body/inertial rate convention, renormalization, integration error. | Attitude kinematics and propagation scenario. | Constant-axis analytical rotation and norm-drift checks. | Attitude error and quaternion norm remain within documented bounds. |

| M10 Sensor models | PLANNED | Convert truth into sampled, noisy measurements. | Noise, bias, drift, rate, dropout, calibration, deterministic seeds. | Initial IMU/GNSS/star-tracker/range models and Lesson 006. | Seed repeatability, statistics, sampling cadence, dropout behavior. | Measurements never alias truth and statistical checks meet tolerances. |
| M11 Linear Kalman filter | PLANNED | Estimate a linear system state with uncertainty. | Prediction, innovation, covariance, process/measurement noise, Kalman gain. | Linear filter and Lesson 007. | Deterministic known system, covariance symmetry, error convergence. | Truth/measurement/estimate remain separate and the filter meets error bounds. |
| M12 Extended Kalman filter | PLANNED | Estimate nonlinear dynamics through local linearization. | Jacobians, nonlinear prediction/measurement, consistency, conditioning. | EKF and Lesson 008. | Jacobian checks, nonlinear synthetic case, covariance validity. | EKF improves the documented baseline without numerical invalidity. |
| M13 Attitude estimation | PLANNED | Fuse gyro and absolute attitude measurements. | Quaternion error state, gyro bias, sensor fusion, attitude-error metrics. | Attitude estimator and analysis plots. | Bias recovery, dropout recovery, quaternion norm, known truth comparison. | Attitude and bias errors meet scenario criteria. |

| M15 Relative motion / Hill frame | PLANNED | Express chaser motion relative to the target. | Relative position/velocity, Hill frame, Clohessy-Wiltshire assumptions. | Relative dynamics and Lesson 009. | ECI-to-Hill consistency, analytical CW cases, round trips. | Relative trajectories match the documented linear-model validity range. |
| M16 Rendezvous guidance | PLANNED | Generate safe reference motion between hold points. | Guidance versus control, waypoints, closing-rate profiles, constraints. | Rendezvous guidance API and scenarios. | Hold-point sequencing, deterministic commands, constraint checks. | Guidance reaches each planned hold point without violating limits. |
| M17 Translational control | PLANNED | Track translation commands with bounded thrust. | Force, impulse, mass, saturation, actuator lag/error. | Thruster model and controller. | Step tracking, saturation, zero-command and mass validation. | Tracking and actuation stay within documented performance/safety bounds. |
| M18 Attitude control | PLANNED | Detumble and track attitude using classical control. | PID, then LQR, gains, stability, saturation, settling time. | Attitude controllers and Lessons 010-011. | Known initial tumble, convergence, torque bounds, saturation. | Error/rate settle within criteria without exceeding actuator limits. |
| M19 Docking corridor | PLANNED | Encode approach geometry and keep-out constraints. | Approach axis, corridor, keep-out sphere, hold points, closing-rate limits. | Safety geometry and corridor checks. | Boundary, inside/outside, closing-rate and hold-point cases. | Every unsafe geometric condition is detected deterministically. |
| M20 Mission state machine | PLANNED | Coordinate approach modes and aborts. | State machines, guards, latching, degraded modes, safety priorities. | Mission modes, transitions, abort behavior. | Nominal transition path and each abort guard. | Illegal transitions are impossible and unsafe inputs reach ABORT. |
| M21 Virtual camera | PLANNED | Generate deterministic docking-camera observations. | Intrinsics, extrinsics, projection, FOV, clipping, sensor frames. | Camera model and synthetic geometry. | Known projections, behind-camera rejection, frame consistency. | Reprojection matches analytical pixels within tolerance. |
| M22 Classical visual pose estimation | PLANNED | Recover target pose with geometric computer vision. | Features, correspondences, PnP, relative pose, reprojection error. | Classical pose pipeline and Lesson 012. | Synthetic known pose, noise sensitivity, outlier/failure cases. | Pose and reprojection errors meet documented bounds before ML begins. |
| M23 ML pose estimation | PLANNED | Compare learned pose cues with the classical baseline. | Dataset design, train/validation splits, confidence, generalization, calibration. | Reproducible model/data pipeline and evaluation. | Held-out pose metrics, seed repeatability, baseline comparison. | Model limitations are documented and performance is no worse than agreed criteria. |
| M24 Fault injection | PLANNED | Reproduce sensor and actuator failures on a schedule. | Fault taxonomy, timing, magnitude, persistence, deterministic scenarios. | Fault framework and scenario schema. | Each fault type, onset/clear timing, seed repeatability. | Faults affect only their intended interfaces and reproduce exactly. |
| M25 Classical fault detection | PLANNED | Detect failures using interpretable residual methods. | Range/rate checks, innovations, sigma thresholds, consistency, latency. | Detectors and degraded-mode interface. | Nominal false alarms, injected detection, threshold boundaries. | Detection/false-positive/latency metrics meet documented targets. |
| M26 ML anomaly detection | PLANNED | Evaluate learned anomaly methods against classical detectors. | Feature leakage, imbalance, temporal validation, precision/recall, latency. | Reproducible anomaly experiment. | Held-out faults, nominal false positives, seed stability, baseline comparison. | Results justify any added complexity and report failures honestly. |
| M27 Monte Carlo validation | PLANNED | Measure mission robustness across uncertainty. | Sampling plans, distributions, confidence intervals, reproducibility, aggregation. | Batch runner, result schema, mission scorecard. | Repeatable seeds, distribution sanity checks, small golden batch. | Success, abort, collision, error, time, and propellant metrics are reproducible. |

| M29 Final portfolio documentation | PLANNED | Present verified capability and learning evidence without overstating scope. | Technical storytelling, traceability, limitations, reproducible demonstrations. | Final README, figures, architecture, verification report, examples. | Clean build from instructions and end-to-end demonstration checks. | A new engineer can reproduce results and distinguish implemented from planned work. |

## Immediate boundary

The current work stops at M04. The implementation includes only idealized
Cartesian two-body propagation, invariant diagnostics, deterministic CSV, and
basic Python plots. M05 — Orbital Invariants, Accuracy Characterization, and
Propagator Validation is the next recommended milestone after M04 and all
previous work configure, compile, and pass their checks.
