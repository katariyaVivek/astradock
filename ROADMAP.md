# AstraDock Roadmap

Milestones are sequential. A milestone is complete only when its lesson/model,
implementation, tests, and stated completion criteria are all satisfied. Future
items describe intent and must not be read as implemented capabilities.

Status vocabulary:

- **IMPLEMENTED**: completion criteria have been verified.
- **IN PROGRESS**: work exists but at least one completion criterion is not yet
  verified.
- **PLANNED**: no implementation claim is made.

## Immediate boundary

The current work stops at M08. The implementation includes idealized
Cartesian two-body propagation, invariant diagnostics, deterministic CSV export,
Python validation plots, timestep-convergence verification, orthonormal `FrameBasis`,
`Matrix3` arithmetic, explicit LVLH basis construction and Direction Cosine Matrices,
`ClassicalOrbitalElements` ($a, e, i, \Omega, \omega, \nu$), perifocal coordinate frame ($PQW$),
bidirectional state $\leftrightarrow$ elements conversion with sub-nanometre accuracy,
`math::Quaternion` (scalar-first $[w, x, y, z]$), Hamilton product composition,
Shepperd DCM $\leftrightarrow$ quaternion conversions, active vector rotations,
`math::EulerAngles` (ZYX sequence), and `attitude::AttitudeState`.

M09 — Attitude Propagation & Quaternion Kinematics is the next recommended milestone after M08 and all
previous work configure, compile, and pass their checks.
